# Analyse économétrique des salaires dans le football professionnel

🇬🇧 [English version](README.md)

Ce projet a été réalisé dans le cadre d’une étude économétrique portant sur les inégalités salariales dans le football professionnel.  
Son objectif est d’analyser les facteurs expliquant les différences de salaire parmi les 463 joueurs de champ ayant la plus forte valeur marchande en septembre 2024.

## 📑 Présentation du projet

L’étude porte sur les joueurs de champ, c’est-à-dire tous les joueurs à l’exception des gardiens de but : défenseurs, milieux de terrain et attaquants.

Nous avons collecté des données de **performance**, **sociodémographiques** et **contractuelles** relatives à la **saison 2023/2024**.  
Après nettoyage et traitement des données, l’échantillon final comprend **463 joueurs**.

Le projet combine :
- une **analyse descriptive** des données,
- et une **analyse économétrique** visant à identifier les principaux déterminants des salaires des joueurs.

## 📌 Objectifs du projet

- 📊 Analyser les disparités salariales entre les joueurs de football professionnels
- 📈 Identifier les variables influençant significativement les salaires
- 🔍 Étudier l’impact des performances sportives, des caractéristiques individuelles, de la popularité et du club d’appartenance sur les salaires

## 📂 Structure du projet

- 📁 `data/` : contient les données utilisées pour l’analyse
- 📁 `scripts/` : scripts R consacrés au nettoyage des données, aux statistiques descriptives et à la modélisation économétrique
- 📁 `results/` : résultats, tableaux et sorties issus des différentes analyses

## 🧾 Principaux résultats

L’étude montre que les différences de salaire ne s’expliquent pas uniquement par les performances sportives attendues.  
D’autres facteurs jouent également un rôle important, notamment :
- les caractéristiques individuelles des joueurs,
- leur popularité,
- et le club auquel ils appartiennent.
